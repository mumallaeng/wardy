현재 연결 범위

Jetson이 /dev/video0·V4L2 USB webcam을 한 번만 읽고 로컬 C++ 처리 frame과 H.264 WebRTC/UDP preview를 분기합니다. 브라우저는 Jetson SQLite의 event·state·등록 자료와 구조화된 inference output을 HTTPS와 WebSocket으로 동기화합니다. 화면에 임시 출력이 표시되면 실제 모델 대신 후속 기능 검증용 값이 사용 중입니다.
